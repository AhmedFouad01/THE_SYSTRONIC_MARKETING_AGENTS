# CREATIVE Production Standard

Version: 1.1 — 2026-10-07

## Objective

Define what “professional creative execution” means inside TSST. This standard was introduced after the first ANVIL pilot showed that strong strategy and detailed briefs can still produce weak visual output when the production gate accepts placeholder-like assets.

## Production ladder

`0 INTAKE → STRATEGY → ART DIRECTION → KEY VISUAL → FORMAT SYSTEM → PRODUCTION → FINISHING → RENDER QA → USER REVIEW`

Stage 0 INTAKE: no render until `TSST/CREATIVE/INTAKE_GATE.md` BLOCKING fields are filled or answered by the user.

Skipping the key-visual or render-QA stages is not allowed for a production request.

## Static/social standard

A professional social asset should demonstrate most of the following as applicable:

- one dominant focal point and clear scan path;
- meaningful crop/scale relationships;
- visual depth from subject/background/material/lighting, not effect stacking;
- brand-specific graphic grammar;
- disciplined typography with credible Arabic/English shaping;
- intentional negative space and edge safety;
- high-quality image integration/retouching;
- channel-specific composition rather than mechanical resizing;
- readable message at real feed size;
- final export without browser chrome, placeholder artifacts or layout debugging traces.

## Key visual standard

The key visual is the campaign's visual proposition. It must answer:

1. What does the eye see first?
2. What visual event makes this campaign recognizable?
3. How does it express the strategy without needing a paragraph?
4. How will it vary across multiple assets without becoming repetitive?
5. What brand rules make it ownable?

If the answer is only “logo + headline + brand color,” the key visual is underdeveloped.

## Motion/video standard

Professional short-form video needs:

- a deliberate opening event within the first seconds;
- beat-based edit structure;
- purposeful shot/scene variation;
- motion typography when useful, not as filler;
- visual continuity and motivated transitions;
- captions designed for the frame and UI;
- coherent sound design / dialogue / music balance;
- color continuity and finishing;
- end card with enough hold to read;
- an actual rendered MP4/MOV for final-review state.

## Minimalism rule

Minimalism is valid only when it remains visually authored. Minimal work still needs contrast, proportion, tension, optical alignment, material/texture control and a clear focal decision. Empty space caused by lack of ideas is not minimalism.

## Variation rule

Campaign consistency means shared grammar, not duplicate layouts. Across a set, vary at least two meaningful dimensions such as:

- subject/image;
- crop or scale;
- focal placement;
- typographic behavior;
- visual metaphor;
- material/texture;
- motion mechanism;
- camera distance or edit rhythm.

## Evidence vs final output

Briefs, storyboards, HTML previews and prompts are planning evidence. They never substitute for final visual production when the request is for actual campaign assets.
