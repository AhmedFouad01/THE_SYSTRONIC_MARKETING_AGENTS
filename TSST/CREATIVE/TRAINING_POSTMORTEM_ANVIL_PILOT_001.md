# Training Postmortem — ANVIL Pilot 001 Creative Execution

Date: 2026-09-24  
Purpose: supervised learning evidence for CREATIVE_AG; not a client campaign result.

## What worked

- strategic continuity concept was coherent;
- art-direction rules were documented carefully;
- scripts, formats, rights cautions and production specs were detailed;
- visual governance protected the logo and brand claims.

## What failed in execution

User review identified that the produced visual set was below professional social-media design level. The recurring failure pattern was essentially **the same dark image/layout with copy and logo changes**, creating placeholder-style assets instead of designed campaign executions.

Observed execution lessons:

1. **Brief quality does not equal visual quality.** A long production spec can still produce weak work.
2. **A system is not a template.** Campaign consistency must preserve a grammar while varying composition, crop, focal subject and visual event.
3. **Text cards are not automatically minimal design.** Without tension, hierarchy, imagery/material depth and optical craft, they read as placeholders.
4. **Hero imagery matters.** The ANVIL identity already supported industrial textures, cinematic people, product curation and premium retail compositions; failing to use those assets/behaviors stripped the brand of its strongest character.
5. **HTML/browser exports are previs, not social deliverables.** The requested campaign medium was social imagery/video, so browser-style outputs were a production-state error.
6. **Motion planning is not editing.** A motion brief cannot be counted as professional Reel/TikTok execution until real rendered video is reviewed.

## Corrective training rules

- Build one strong key visual first; do not begin with seven templates.
- Require a focal visual event for every asset.
- For each campaign phase, define a distinct visual job: tease, reveal and reinforcement should not be identical layouts with different copy.
- Use source imagery, product, people, texture and material when the brand system calls for them.
- Separate exact brand masters from generated imagery; composite official elements afterward.
- Recompose each target format.
- Render and inspect the actual output before accepting it.

## Acceptance consequence

The ANVIL creative planning remains useful evidence, but the prior image/video production is **not accepted as proof of professional production capability**. It should be treated as a supervised failure fixture for the new production stack.
