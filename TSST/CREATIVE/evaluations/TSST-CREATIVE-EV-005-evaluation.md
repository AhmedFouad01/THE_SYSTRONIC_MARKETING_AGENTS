# TSST-CREATIVE-SK-005 Evaluation — Typography System

Status: `QUEUED`  
Skill status: `UNVALIDATED`

## Task

Build an Arabic/English typography system for a fictional brand and apply it to a social post, a data-heavy slide, and a responsive web page.

## Required deliverables

- licensed font inventory and delivery constraints;
- Arabic/Latin pairing rationale;
- semantic type roles and tokens;
- mixed-script and fallback rules;
- rendered application samples;
- readability test log.

## Test conditions

The fixture includes long Arabic headings, mixed Arabic/Latin numerals, a missing preferred weight, and a platform with limited font embedding.

## Evaluation emphasis

Score glyph coverage, hierarchy, line metrics, pairing, cross-channel adaptation, licensing, and final-size readability.

## Automatic failures

Unlicensed font; missing Arabic glyph test; artificial styling used to fake weights; or evaluation on Latin placeholder text only.
