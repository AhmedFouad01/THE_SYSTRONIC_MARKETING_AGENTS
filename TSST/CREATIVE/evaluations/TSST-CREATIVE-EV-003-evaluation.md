# TSST-CREATIVE-SK-003 Evaluation — Design Tokens

Status: `QUEUED`  
Skill status: `UNVALIDATED`

## Task

Create a tool-agnostic token hierarchy for a fictional bilingual brand used in social creative, executive decks, and a light/dark responsive website.

## Required deliverables

- naming grammar and token taxonomy;
- typed base and semantic tokens;
- aliases and theme overrides;
- channel mapping;
- deprecation rule;
- validation report.

## Test conditions

The fixture includes duplicated raw colors, a missing dark-theme role, and a legacy name. Validation must detect missing aliases, cycles, type mismatches, and contrast issues.

## Evaluation emphasis

Score semantic clarity, portability, alias integrity, theme design, naming consistency, and resolved-value tests.

## Automatic failures

Tool-owned canonical meaning; circular or broken aliases; raw-value names used as semantic roles; or an untested claim of accessibility.
