# TSST-CREATIVE-SK-004 Evaluation — Visual Hierarchy & Layout

Status: `QUEUED`  
Skill status: `UNVALIDATED`

## Task

Review three evaluator-supplied flawed creatives: one social asset, one executive slide, and one responsive web page. Diagnose and correct hierarchy and layout problems.

## Required deliverables

- intended reading order for each creative;
- annotated issue list with severity and impact;
- corrected grid, spacing, alignment, and grouping rules;
- revised layouts at required sizes;
- visual QA record.

## Test conditions

Include long Arabic text, a misleading focal point, inconsistent spacing, and a mobile layout that cannot be solved by simple scaling.

## Evaluation emphasis

Score observable diagnosis, prioritization, content preservation, responsive logic, and whether revisions improve the assigned task.

## Automatic failures

Taste-only critique; copied Primer appearance; erased essential content; no RTL test; or no actual-size review.
