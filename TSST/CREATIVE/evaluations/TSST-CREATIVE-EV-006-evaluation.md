# TSST-CREATIVE-SK-006 Evaluation — Color System & Accessibility

Status: `QUEUED`  
Skill status: `UNVALIDATED`

## Task

Build a semantic light/dark color system for a fictional brand and validate it across text, controls, validation states, and a categorical chart.

## Required deliverables

- base palette and semantic role map;
- theme and state aliases;
- contrast matrix with ratios and criteria;
- non-color cue rules;
- chart palette test;
- remediation and QA record.

## Test conditions

Include one brand accent that fails on light backgrounds, a disabled state, an error state, and two categories that are difficult to distinguish under color-vision simulation.

## Evaluation emphasis

Score semantic construction, accurate contrast checks, state coverage, non-color cues, theme consistency, and corrections.

## Automatic failures

Color-only status meaning; claimed accessibility without measured pairs; unresolved required contrast failure; or copying Primer's palette.
