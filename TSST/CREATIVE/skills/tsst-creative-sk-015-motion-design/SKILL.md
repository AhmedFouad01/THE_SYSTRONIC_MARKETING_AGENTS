# TSST-CREATIVE-SK-015 — Motion Design

Status: `UNVALIDATED`  
Training installed: 2026-09-24  
Owner: `CREATIVE_AG`

## Objective

Animate brand/typographic/graphic systems with intentional timing, easing, hierarchy and narrative function.

## Source / provenance

Adobe After Effects official keyframe/animation principles + professional motion-graphics practice.

## Required method

1. Define what changes over time and why before choosing effects.
2. Use keyframes/easing to control acceleration, emphasis and reading time; avoid default linear movement unless justified.
3. Animate hierarchy: primary information moves/appears first, support second, signature last.
4. Use masks, scale, position, opacity and transforms as compositional tools, not random decoration.
5. Inspect motion at normal playback speed and on a phone-sized frame.

## Failure patterns

- every element flying in independently
- default presets used as the concept
- logo animation longer than the message
- motion too fast to read Arabic
- constant movement that competes with the focal point

## Practical evaluation

Build an 8–12 second branded motion reveal with a clear visual mechanism, readable bilingual type and deliberate easing; inspect rendered key frames and full playback.

## Validation rule

Package installation and study do not validate the skill. Validation requires actual evidence appropriate to the medium. Render-dependent skills cannot pass on briefs, prompts, HTML previews or unrendered storyboards alone.
