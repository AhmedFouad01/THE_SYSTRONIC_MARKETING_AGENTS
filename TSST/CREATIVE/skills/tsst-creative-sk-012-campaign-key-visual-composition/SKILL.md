# TSST-CREATIVE-SK-012 — Campaign Key Visual & Composition

Status: `UNVALIDATED`  
Training installed: 2026-09-24  
Owner: `CREATIVE_AG`

## Objective

Create a memorable campaign visual proposition that can generate a family of assets without collapsing into repetitive templates.

## Source / provenance

Campaign art-direction practice, editorial composition and brand-specific visual systems.

## Required method

1. Translate the strategic idea into a visual event/metaphor/mechanism that works without a long caption.
2. Define focal subject, visual tension, foreground/midground/background, crop behavior and signature brand device.
3. Prove the key visual in one hero composition before scaling into a campaign system.
4. Define what stays constant and what is allowed to vary across the campaign.
5. Reject directions that only become recognizable after the logo is added.

## Failure patterns

- “use brand colors” treated as a key visual
- an art-direction moodboard without a hero execution
- visual metaphor unrelated to the strategy
- one composition mechanically duplicated across all formats

## Practical evaluation

Develop 3 key-visual directions for one brief, select one, render a hero 4:5 post plus a structurally different 9:16 story adaptation.

## Validation rule

Package installation and study do not validate the skill. Validation requires actual evidence appropriate to the medium. Render-dependent skills cannot pass on briefs, prompts, HTML previews or unrendered storyboards alone.
