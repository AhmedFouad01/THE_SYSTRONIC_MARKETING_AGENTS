# TSST-CREATIVE-SK-016 — Short-form Video Editing

Status: `UNVALIDATED`  
Training installed: 2026-09-24  
Owner: `CREATIVE_AG`

## Objective

Edit Reels/TikTok/short video with strong opening, beat structure, shot purpose, pacing, captions and platform-native visual behavior.

## Source / provenance

Adobe Premiere official editing/export workflow + TikTok official vertical/native creative guidance.

## Required method

1. Write an edit map: hook, proof/context, reveal/value, memory/CTA.
2. Choose cuts from action, gaze, beat, information change or emotional shift—not arbitrary timer intervals.
3. Keep the first seconds immediately understandable while preserving intrigue.
4. Use B-roll/detail/scale changes to create rhythm and hide cuts; do not rely on static slide sequences.
5. Render and review the final piece muted and with sound.

## Failure patterns

- slideshow of near-identical cards
- opening logo before any viewer value
- repeated same-duration cuts with no rhythm
- text too dense for viewing time
- cross-platform watermarks and unsafe UI placement

## Practical evaluation

Edit a 15–20s short from mixed footage/stills into a native vertical story with a distinct first-3-second hook and final rendered video.

## Validation rule

Package installation and study do not validate the skill. Validation requires actual evidence appropriate to the medium. Render-dependent skills cannot pass on briefs, prompts, HTML previews or unrendered storyboards alone.
