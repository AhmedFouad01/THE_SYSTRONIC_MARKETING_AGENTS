# TSST-CREATIVE-SK-030 — Usability Testing, Heuristic Evaluation & UX QA


Status: `UNVALIDATED`

Scope: Product UI/UX for the Systronic CRM MVP and future enterprise SaaS interfaces.


## Objective
Validate designs with structured heuristic review and realistic task-based usability testing before visual approval and implementation handoff.


## Trigger
Use after low/mid fidelity and again after interactive high-fidelity prototype or implemented UI.


## Sources
- https://www.nngroup.com/articles/how-to-conduct-a-heuristic-evaluation/
- https://www.nngroup.com/articles/usability-101-introduction-to-usability/
- https://media.nngroup.com/media/articles/attachments/Usability-Testing-101_SizeA4.pdf


## Workflow
1. Define realistic tasks and success criteria.
2. Run heuristic review against agreed principles.
3. Prioritize findings by severity and task impact.
4. Test with realistic users when available; 5–8 participants is a typical qualitative guideline, not a rigid law.
5. Observe behavior before asking opinions.
6. Track completion, critical errors, hesitation and recovery.
7. Retest resolved high-severity issues.


## Output contract
Heuristic audit; usability script; findings log; severity; remediation recommendations; pass/fail UX gate.


## Guardrails
- Do not treat stakeholder preference as usability evidence.
- Do not lead participants.
- Do not mark UI ready with unresolved critical task blockers.
- Visual polish does not override failed task completion.


## Practical evaluation
Test 6 MVP tasks: lead intake, find contact, move deal, create task, inspect journey, view report; no unresolved severity-1/2 issue at handoff.
