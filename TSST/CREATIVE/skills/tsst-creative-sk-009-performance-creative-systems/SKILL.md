# TSST-CREATIVE-SK-009 — Performance Creative Systems

Status: `UNVALIDATED`  
Training installed: 2026-09-24  
Owner: `CREATIVE_AG`

## Objective

Turn one approved message/offer into a coherent system of platform-native creative hypotheses without sacrificing brand craft.

## Source / provenance

Meta official Reels creative guidance + current platform creative specifications; SPARK supplies measurement/test constraints.

## Required method

1. Write the creative hypothesis before making the asset: audience context → hook → message → visual mechanism → expected observable signal.
2. Create variants that change one meaningful variable at a time where learning is intended; distinguish performance variants from simple aesthetic alternatives.
3. Protect the brand grammar while adapting opening frame, pacing, format and CTA to platform behavior.
4. Keep paid creative independently understandable; do not assume viewers saw earlier campaign posts.
5. Pass all candidate variants through CREATIVE visual QA and SPARK platform/measurement review.

## Failure patterns

- six copy swaps on one template presented as six ideas
- generic “hook” text with no visual hook
- changing multiple test variables while claiming a clean winner
- performance optimization used as a reason to weaken brand fidelity

## Practical evaluation

Given one offer/message and two platforms, build six genuinely distinct hypotheses, then produce at least two rendered candidates and a variable map.

## Validation rule

Package installation and study do not validate the skill. Validation requires actual evidence appropriate to the medium. Render-dependent skills cannot pass on briefs, prompts, HTML previews or unrendered storyboards alone.
