7. Checks before booting: counts per table against the dump, `schema_migrations`, triggers enabled, object counts, a
   schema diff against a database migrated from `v-before-sprint` (must be empty).
8. Boot the live version (`v-before-sprint`) against it with a clean environment; health check; a curl smoke test
   with a drill user.
9. Only with Ahmed's yes: rehearse `next`'s migrations on the copy (names, duration, counts before and after).
10. Evidence here and on the board: source, file name, size, sha256, versions, restore exit code and duration, the
    counts, the checks, RPO, and what the drill does not cover.
11. The same day: stop the cluster; Ahmed deletes the folder by hand; check it is gone and no postgres runs.
