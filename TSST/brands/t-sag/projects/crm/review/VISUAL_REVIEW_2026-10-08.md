## Ahmed clarifications 2026-10-09 (these supersede the matching rows above)
- **R10 (corrected):** a lead with no phone and no email is **not a lead**; a name alone is not enough. Creating a lead (dialog, import, API, and later Lead Ads) **requires at least one contact channel: phone or email**. Validation messages are AR/EN. Import rows that fail this go to row errors. Existing leads without either get a "missing contact" flag/filter. The «عميل محتمل» term note is dropped.
- **R01 (expanded):** the pipeline board supports **drag & drop of deal cards between stages** (React Aria DnD, keyboard-accessible, RTL), using the existing stage-transition API and its rules. **Stage names are user-defined**: a pipeline settings screen to add, rename, reorder and archive stages (single name field per R08).
- **R02 (method):** alignment, heights, line-height and spacing between objects are a **recurring core problem**. Adopt an open-source design/layout skill for agents (Ahmed recalls one named like "Impeccable"; Lead to verify and install with approval) and enforce one spacing/height/rhythm scale across the kit.
- **R03 (expanded):** keep ONE theme. Remove navy. Extra colors are allowed only when **derived from the brand colors at the same saturation and brightness** (a harmonious extended palette as tokens), light and dark.
- **R06 (changed):** remove the "Coming soon" badge text entirely. An upcoming nav item renders **disabled** with a small **amber/orange dot** at the logical end, plus a tooltip "Coming soon / قريبًا".
- **R07 (expanded), grids like HubSpot:**
  - a **freeze columns** option (first 1, 2 or 3);
  - **drag to reorder columns** (status before contact, owner before status, and so on);
  - a **column chooser popup** listing every property of the object, with search and checkboxes, reflecting the saved view;
  - **inline edit in the grid** (click the status cell → select → save), under the same permissions and validation as the panel.
