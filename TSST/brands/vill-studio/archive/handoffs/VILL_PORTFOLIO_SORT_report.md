## 3. Methodology & Clustering Execution

### Step 1 — Local CLIP Embeddings & Agglomerative Clustering
- **Feature Extraction**: Run locally via `open_clip ViT-L-14` (pre-trained OpenAI weights) on CUDA in batch size 32. All EXIF orientations were applied before tensor transformation. Feature vectors L2-normalized.
- **Zero-Shot Space Tagging**: 12 interior classification prompts evaluated simultaneously against embeddings (`kitchen`, `reception-living`, `bedroom`, `bathroom`, `dressing`, `ceiling-gypsum`, `flooring`, `paint-walls`, `facade`, `furniture-pieces`, `workshop`, `other`).
- **Duplicate Detection**:
  - Exact file matches detected via SHA-256 hashes.
  - Perceptual matches detected via `imagehash.phash` Hamming distance $\le 4$.
  - Within each duplicate cluster, the highest resolution and highest Laplacian variance (sharpness) was retained as master; the remaining 53 files were flagged for `_duplicates/`.
- **Temporal Bursting & Distance Threshold**:
  - Initial photo bursts segmented with a 45-minute inter-photo time gap threshold.
  - Agglomerative clustering with average cosine linkage merged bursts of identical scenes across days ($\ge 0.88$ cosine similarity).
  - Outlier bursts and oversized clusters ($> 40$ items) were iteratively split to produce 59 balanced contact-sheet groups.

## 4. Script Errors & Technical Resolutions

1. **Python Standard Library Shadowing**:
   - *Issue*: A script named `copy.py` inside `_work/` shadowed Python's standard library module `copy` when PyTorch (`torch`) was imported, causing `from copy import deepcopy` to fail.
   - *Resolution*: Sanitized `sys.path` in all scripts and executed commands from repository root.
2. **Windows CP1252 Arabic-Indic Encoding**:
   - *Issue*: 5 source files contain Arabic-Indic numerals (`IMG_٢٠١٨٠٧١٨...`). Standard Windows console CP1252 threw `UnicodeEncodeError` when printing to stdout.
   - *Resolution*: Implemented `sys.stdout.reconfigure(encoding='utf-8')` across all scripts.
3. **Cluster Percolation Collapse**:
   - *Issue*: Unconstrained single-linkage agglomerative clustering collapsed 1,286 photos into one mega-cluster because all photos are interior finishes.
   - *Resolution*: Enforced time-burst chunking prior to visual agglomerative clustering, with average linkage and strict $\le 40$ size partitioning.
4. **Before-After Exact Filename Validation**:
   - *Issue*: Typographical timestamp during initial draft (`20200521_145610.jpg`) triggered `FileNotFoundError`.
   - *Resolution*: Added existence verification against `SOURCE_DIR` and mapped exact timestamps from `clusters.json` (`20200521_100515.jpg` and `20200609_184533.jpg`).
