# C3 Routing Reference Implementation

Reference only. No provider SDK dependency.

It verifies:
- volume is not executive complexity;
- code-heavy tasks can route to a coding tier;
- high-impact ambiguity escalates;
- repeat failures escalate;
- low budget cannot silently consume executive calls;
- external/internal mutation tools are authority-gated;
- large catalogs defer non-frequent tools.

Run:

```bash
cd reference_implementation_c3
python -m unittest discover -s tests -v
```
