# TSST-LEAD-SK-030 — Progressive Deep Onboarding

Owner: TSST Lead  
Version: 1.0  
Status: `UNVALIDATED`  
Evaluation: not run; future reservation `TSST-LEAD-EV-030`.

## Inputs and trigger

Use for explicit user request to begin or resume onboarding. Read the confirmed operating profile and the user's current objective. Identify missing decision-critical inputs before recommending action; unknowns remain explicit.

## Method

Use the staged framework; ask only the next small decision-relevant question set; capture source and confirmation separately; summarize each stage and let the user correct or defer it.

## Output and acceptance

Deliver confirmed profile entries, unresolved questions and next stage. Show the decision supported, evidence versus assumptions, rejected alternatives, owner and next authorized step. A reviewer should be able to trace the recommendation back to inputs and identify what would change it.

## Boundary and failure check

Do not start automatically or populate company facts from assumptions. Apply the [Lead operating contract](../../AGENT.md). Check that the output resolves the triggering decision, preserves specialist ownership and does not claim validation from its own completion.
