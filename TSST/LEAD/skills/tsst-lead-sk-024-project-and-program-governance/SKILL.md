# TSST-LEAD-SK-024 — Project and Program Governance

Owner: TSST Lead  
Version: 1.0  
Status: `UNVALIDATED`  
Evaluation: not run; future reservation `TSST-LEAD-EV-024`.

## Inputs and trigger

Use for multi-agent deliverable, dependencies and decision date. Read the confirmed operating profile and the user's current objective. Identify missing decision-critical inputs before recommending action; unknowns remain explicit.

## Method

Decompose outcomes into accountable work packages; set acceptance criteria, dependencies and review dates; track blockers and change impact; escalate scope and resource conflicts early.

## Output and acceptance

Deliver program plan with work-package IDs, milestones, owners and change log. Show the decision supported, evidence versus assumptions, rejected alternatives, owner and next authorized step. A reviewer should be able to trace the recommendation back to inputs and identify what would change it.

## Boundary and failure check

Task completion does not equal business outcome or user acceptance. Apply the [Lead operating contract](../../AGENT.md). Check that the output resolves the triggering decision, preserves specialist ownership and does not claim validation from its own completion.
