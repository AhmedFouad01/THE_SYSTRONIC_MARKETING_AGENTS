# SV-01 Visual identity · v0.1 SKELETON · 2026-10-08

**What it is:** we build a brand's visual identity from scratch, or **rebrand** one (fix a logo or colours the client made below standard), and then apply it to every channel.
**Variants:** new · rebrand · applications-only (the identity exists and we build the social setup kit).

## Client deliverables (user definition 2026-10-08)
- Logo (new or refined) + logo variations matrix.
- Colour palette (main + supporting, measured hex).
- Typography (Arabic + Latin brand fonts).
- **Brand guidelines book**: brand personality, the "visual DNA", art direction, and how the identity applies across designs.
- Art direction: how the identity is applied to different designs.
- **Social media setup kit**: cover photos, profile pictures, highlight/feature covers, story templates, reel covers/templates, post templates.
- Source + export files (formats: OPEN, decide per job).

## Blocking intake questions (Lead asks before any work)
1. New or rebrand? For a rebrand: what is weak, and what must stay?
2. Existing assets: logo source files, fonts, colours. Verify everything against the user/client, never against an agent draft (lesson 2026-10-08, Cairo vs Inter).
3. Business, audience, competitors, positioning in one paragraph. If missing, run a light SV-02 first.
4. Personality: 3–5 words + what the brand must never feel like.
5. References liked and disliked (taste anchor only, never copied).
6. Platforms to set up, languages (AR/EN, RTL), deliverable formats, deadline, approver.

## Quality gates
Logo matrix pixel-verified (background theme vs file name). Colours named by measured hue. Brand fonts confirmed by the user. Contrast measured (SK-006), with a separate logo rule. Platform sizes from TOOLCHAIN.md. RTL checked. The FINAL_ASSET_GATE scored review applies.

## Common mistakes (our own, so far)
- Colour named from memory (navy vs petrol).
- Fonts taken from an agent-written guideline draft (Cairo).
- Inverted logo variants.
- Colour overlays on photos.
- Template sameness across slides.

- Guidelines sections: purpose → personality/voice → logo (+ misuse, clear space, minimum size) → colour (HEX/RGB/CMYK) → type (AR + EN) → imagery/art direction → graphic devices → layouts/applications → accessibility.

## Lessons log
- **2026-10-09 · VILL social-setup-01 (first live job, applications-only), APPROVED after round 2 of 3.**
  1. Intake first worked: 4 questions (platforms, language, highlights, who posts) settled the scope before any design.
  2. Gemini/Antigravity specs were unreliable. SPARK + Lead verified the specs on official pages. Instagram does NOT publish the avatar size, the highlight cover size or the grid crop, so use practice defaults and check them after the first upload.
  3. A profile mock (avatar + highlights + bio + first grid row) catches what single files hide. It showed 2 stone-wall tiles side by side, which were fixed.
  4. Avatar: keep the mark at ≤80 % of the circle and drop tags under ~7 px at 110 px.
  5. 3:4 source photos vs 9:16 story/reel: the ≤1.25× upscale cap rules out full-bleed, so use a passe-partout or a photo band with intentional type/logo zones.
  6. Voice by platform: LinkedIn formal English and third person. Locations go only in that project's posts, never in bios. Brand text never implies a single project or states a count.
  7. CTA: the website goes in the link field, not the bio text (Instagram links in the bio are not clickable).
