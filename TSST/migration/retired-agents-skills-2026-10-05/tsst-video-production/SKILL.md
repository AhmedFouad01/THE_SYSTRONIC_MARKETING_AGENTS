# TSST Video Production

1. Define hook, narrative beats, shot list, duration, platform, aspect ratio and end action.
2. For each shot define purpose, subject, environment, framing, camera movement, lighting, motion and continuity anchors.
3. Use reference images/characters/objects for consistency when supported.
4. Use first/last frames and extension only when they support continuity.
5. Treat generated clips as source material until final edit structure, subtitles, audio, color and end card are complete.
6. Avoid static slideshow behavior unless intentionally approved.
7. Check first 1–3 seconds, safe zones, subtitle legibility, audio balance, exposure/color continuity and end card readability.
8. Final status cannot exceed FINAL_FOR_USER_REVIEW without explicit release approval.
