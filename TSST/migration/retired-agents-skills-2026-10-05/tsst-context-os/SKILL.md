# TSST Context OS

Follow the installed TSST Context OS as the operating layer.

Workflow:
1. Resolve project/workstream/state_scope.
2. Recover latest verified checkpoint/current status.
3. Rank sources by authority and supersession before similarity.
4. Exclude unrelated projects and stale/duplicate context.
5. Build a bounded Context Pack.
6. Select only necessary TSST specialist skills/tools.
7. Return evidence locators, conflicts, unknowns and exact next action.
8. End substantial work with checkpoint candidate and do_not_repeat.

Never promote a model inference or generated summary over canonical source evidence.
