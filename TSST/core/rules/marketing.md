# Rules pack — marketing and research

Load for strategy, copy, campaigns, paid media or research. Core rules still apply.
Original wording: `TSST/decisions/rules-history.md`.

- **R28 Marketing order.** LENS (story/copy) → SPARK (formats/KPIs) → CREATIVE; parallel only when
  their questions don't overlap.
- **R29 Research route.** Broad gathering, long reads and web research go first as a paste-ready
  Gemini app request (ROLE B); launch-blocking facts are re-verified on the live official page.
- **R64 Propose tracking unasked** (owner 2026-11-12): every ad, landing or campaign deliverable lists in one or two lines what
  else it needs to work (pixel + events, UTMs, hosting/domain, CAPI, reporting) and asks for a yes. Propose; don't build unasked.
- **R65 Gate lessons first** (owner 2026-11-12): landing and order pages start from the gate checklist
  (`~/.claude/skills/landing-page-build/SKILL.md`, see TSST-LENS-SK-014); after each gate its blocker/major issues are added there.
