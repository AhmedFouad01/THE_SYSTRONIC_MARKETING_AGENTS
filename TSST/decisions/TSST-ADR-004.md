# TSST-ADR-004 — Runtime-neutral roster (Claude + Codex), plan-aware model mapping, Antigravity retired

Date: 2026-10-05. Decision owner: user. Integration owner: TSST Lead. Extends TSST-ADR-003.
Status: APPROVED.

## Authority
User instruction in chat (Arabic, 2026-10-05), summarised: ADR-003 only covered Claude. Make one
general rule for every runtime we work with: when Codex or Claude gets a task it must know which
TSST team agent to use, which skills, and which model *it actually has* on the user's plans
(**ChatGPT Plus** for Codex, **Claude Pro** for Claude) — never models it doesn't have. Remove
Antigravity (Gemini) from the system: too many permission prompts and no mobile remote control.

## Decision
1. **One neutral source.** `TSST/context/roster.yaml` (agents, team, identity file, default tier,
   permissions, role rules; no model names) + `TSST/context/agent-contract.md`. Runtime agent
   files for Claude (`.claude/agents/tsst-*.md`) and Codex (`.codex/agents/tsst-*.toml`) are
   generated by `TSST/context/gen_runtime_agents.py`; `--check` detects drift. Same names in both
   runtimes: `tsst-lens`, `tsst-spark`, `tsst-creative`, `tsst-dev`, `tsst-reader`.
2. **Two-layer model routing.** TSST logic says agent + tier only. `TSST/bus/runtimes.yaml` maps
   tier → model · effort per runtime *and plan*: Claude Pro FAST haiku · WORK sonnet · CODE sonnet
   (high) · DEEP opus (main); Codex/ChatGPT Plus FAST gpt-6-luna low · WORK gpt-6.1-sol medium ·
   CODE gpt-6.1-sol high · DEEP gpt-6-astra high. A runtime that lacks a mapped model falls back to
   the next tier UP and records it (`models.yaml` rule); model lists are re-verified from the
   runtime's own picker/cache, never from memory.
3. **Lead per runtime.** The runtime's main session is the Lead (boot, Skill Plan, acceptance).
   Codex Lead runs on its default (`work`) model; DEEP-only decisions use `--profile deep`
   (Astra; scarce on Plus) or a bus task to the Claude Lead.
4. **Antigravity retired.** `gemini` runtime `status: retired`; adapter kept as history; Gemini-era
   `.agents/skills` wrappers archived to `TSST/migration/retired-agents-skills-2026-10-05/` and
   replaced by one `tsst-router` skill so Codex auto-loads TSST routing. Historical bus/evidence
   files are untouched. *Note 2026-10-06 (TSD-018):* Gemini Desktop is allowed as a manual
   external tool run by Ahmed (`TSST/context/adapters/gemini-desktop.md`); this does not revive the
   `gemini` runtime or add an agent.
5. **Enforcement.** Claude: PreToolUse dispatch hook. Codex: bus `team`/`skills` checks + generated
   `developer_instructions`; no Codex hook is claimed until verified.
