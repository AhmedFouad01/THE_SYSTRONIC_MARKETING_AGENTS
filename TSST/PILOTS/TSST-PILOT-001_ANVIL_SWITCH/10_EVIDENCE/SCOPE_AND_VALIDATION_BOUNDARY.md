1. Current user request: binding project scope, message territory, budget and execution gate.
2. Confirmed TSST operating profile and business context: user-reported context, not independent audit.
3. Existing ANVIL boards: visual reference within this pilot, not a license to redesign or alter originals.
4. Current official platform guidance: mechanics/policy evidence to the extent retrieved; inaccessible pages recorded as unverified.
5. Specialist/Lead assumptions and recommendations: clearly labeled and replaceable by confirmed inputs.

No fictional evaluation fixture or historical skill score is used as ANVIL customer evidence. No numerical campaign performance values are synthesized. File hashes establish which read-only inputs were used, not their factual accuracy.
