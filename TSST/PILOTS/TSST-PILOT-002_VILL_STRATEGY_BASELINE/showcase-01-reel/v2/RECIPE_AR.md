# ريل العلمين — خطوات التوليد على موقع ماجنيفيك

كل لقطة بنفس الخطوات. الصور الأصلية في فولدر:

```
TSST/brands/vill-studio/assets/source/products-raw/
```

## الخطوات الثابتة لكل لقطة (١ لـ٤)
١. ارفع الصورة المكتوبة تحت اللقطة.
٢. توسيع الصورة للمقاس الطولي ٩:١٦، من فوق وتحت بس، والصق وصف التوسيع.
٣. تكبير الجودة مرتين، بالإعدادات دي:

```
Upscale: creative, 2x, preset subtle, FilmAndPhotography, resemblance 6, creativity -2
```

٤. احفظ الصورة، وبعدين افتح الفيديو واختار الموديل ده:

```
Kling 2.5 — 5 s — 1080p — 9:16 — start frame only — sound off
```

٥. الصق وصف الحركة في خانة الوصف، والممنوعات في خانة الممنوعات.
٦. احفظ الفيديو في فولدر `v2/clips/` بالاسم المكتوب.

## الممنوعات (نفسها لكل اللقطات، وزوّد عليها سطر اللقطة)

morphing, warping or melting walls, wavy lines, texture crawling, flicker, flashing, strobing light, added objects, extra furniture, extra lamps, people, hands, pets, text, logo, subtitles, watermark, handheld shake, fast zoom, orbit, lens flare, fog, haze, colour shift to blue, saturated orange
