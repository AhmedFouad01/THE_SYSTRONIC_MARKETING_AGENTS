# TSST Final Asset QA

Use TSST/CREATIVE/FINAL_ASSET_GATE.md.

Still checks:
- requested dimensions/format;
- exact logo/product geometry;
- focal hierarchy at feed/thumbnail size;
- compositing edges/light/shadow;
- Arabic/Latin typography;
- safe zones/crops;
- rights/provenance;
- actual render inspected.

Video checks:
- actual final render exists;
- first 1–3 second hook;
- subtitles/UI safety;
- intentional motion/editing;
- audio mix;
- color/exposure continuity;
- readable end card;
- phone-scale review and representative-frame inspection;
- rights/provenance.

If any critical item fails, downgrade to PREVIS or PRODUCTION_DRAFT.
