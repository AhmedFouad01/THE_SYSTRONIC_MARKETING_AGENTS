# TSST Image Production

1. Preflight official brand/product/reference assets and rights.
2. Define visual concept, subject, environment, composition, light, lens/perspective, palette and negative space before generation.
3. Choose fast image generation for exploration/variants; choose professional image generation for high-fidelity final-quality candidates and complex layout/text needs.
4. Use reference images deliberately and preserve identity/product geometry.
5. Do not trust generation for exact logos or legally/brand-critical marks when an approved master can be composited.
6. Produce native requested aspect ratios; do not rely only on mechanical crops.
7. Run anatomy/artifact/logo/text/Arabic/edge/light/shadow/color QA.
8. Mark output PRODUCTION_DRAFT until actual render passes TSST final asset checks.
