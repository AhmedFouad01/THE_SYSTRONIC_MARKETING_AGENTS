# Systronic CRM — Three UI Direction Briefs v0.1


Status: UX-04 PRE-FIGMA DIRECTION BRIEF
Owner: CREATIVE_AG
Rule: all directions use the same accepted UX architecture. Differences are visual/interaction emphasis, not product semantics.


## Direction A — Precision Workspace


Intent:
Maximum daily efficiency, calm density and low visual noise.


Visual mechanism:
- strong navy text/structure on neutral surfaces;
- cyan appears primarily as selection/focus/current-context signal;
- almost no decorative red;
- crisp 1px borders;
- compact sidebar;
- flat work surfaces with minimal card framing;
- typography and spacing do most hierarchy work.


Interaction feel:
- fastest scanning;
- keyboard-friendly;
- tables feel primary;
- side panel visually lightweight;
- command palette integrated as an expert accelerator.


Reference principle family:
Linear-class restraint/productivity, without copying its component geometry or identity.


Risk:
Can become too generic unless Systronic signal language is deliberately embedded in active states and micro-details.


## Direction B — CRM Canvas


Intent:
Make records, views and relationships feel like a configurable operating canvas.


Visual mechanism:
- clear view controls;
- stronger table/pipeline mode switching;
- record side panel feels like a persistent contextual workspace;
- more visible chips/status/context metadata;
- controlled modular sections, still border-first and compact;
- slightly more surface layering than Direction A.


Interaction feel:
- strongest for teams living in lists, filters, pipelines and record details;
- saved-view mental model is prominent;
- object relationships are easier to scan.


Reference principle family:
Attio-class CRM data interaction and master-detail thinking, without copying screens or brand styling.


Risk:
May become visually busy if chips/metadata are not tightly governed.


## Direction C — Systronic Signal


Intent:
Create a recognizably Systronic premium enterprise product without relying on the logo.


Visual mechanism:
- deep navy structural rails/anchors;
- subtle angular “signal cut” motif derived from the brand’s geometric strike language;
- cyan used for active signal paths, focus and selected context;
- red limited to tiny brand punctuation, never used as generic error;
- pale oversized geometric brand fragment may appear only in genuinely empty/quiet surfaces, never behind dense data;
- tighter premium typography rhythm;
- dark mode receives equal attention from the start.


Interaction feel:
- same speed and density as A/B;
- stronger branded sense of place;
- active context feels like “signal on / system engaged” rather than decorative theming.


Reference principle family:
Original Systronic product language built from the supplied identity DNA.


Risk:
Angular motif can become decorative noise. It must be constrained to shell, active-state and empty-state roles, not repeated on every component.


## Required comparison boards


Each direction must show the same evidence set:
1. Home / work queue.
2. Leads or Contacts table.
3. Deals pipeline.
4. Record side panel.
5. Tasks/follow-up.
6. Insights / campaign performance.
7. Command palette.
8. Arabic RTL primary.
9. English LTR sample.
10. Narrow/mobile state.
11. Light theme.
12. Dark theme sample.


## Comparison dimensions


User/Lead review should compare:
- task clarity;
- scan speed;
- density;
- Arabic quality;
- visual distinctiveness;
- brand fit without logo;
- dark-mode hierarchy;
- data-table credibility;
- pipeline usability;
- record-detail context;
- reporting clarity;
- implementation scalability.


## Approval rule


Written descriptions are not sufficient for direction selection.
The user approval gate opens only after all three directions are built in Figma at comparable fidelity using the same content and task architecture.
